Manual Detallado de JavaScript

Guía paso a paso explicada concepto por concepto.

1. Introducción y Sintaxis Básica

JavaScript es el lenguaje de programación que dota de interactividad a las páginas web. Las instrucciones suelen terminar con un punto y coma (;). Para mostrar mensajes usamos console.log().

console.log("¡Hola desde la consola de JavaScript!");

2. Variables: let y const

Las variables son espacios en memoria para guardar datos. En JavaScript moderno usamos:

  • let: Para valores que pueden cambiar o reasignarse.
  • const: Para valores fijos que nunca cambian.
let puntaje = 10;
puntaje = 15; 
const pi = 3.1416;

3. Tipos de Datos Primitivos

  • String: Textos entre comillas ("Sara").
  • Number: Numéricos enteros o decimales (100).
  • Boolean: Valores lógicos true o false.
let nombreUsuario = "Carlos";
let edad = 22;
let esMayorDeEdad = true;

4. Operadores Aritméticos y de Comparación

Permiten realizar operaciones matemáticas y comparaciones estrictas (=== compara valor y tipo de dato).

let comparacion = (5 === "5"); // false

5. Estructuras de Control (if / else)

Permiten tomar decisiones lógicas en nuestro programa dependiendo de condiciones.

let calificacion = 85;
if (calificacion >= 90) {
    console.log("Sobresaliente");
} else {
    console.log("Aprobado");
}

6. Bucles y Ciclos (for)

Automatizan tareas repetitivas de forma eficiente.

for (let i = 1; i <= 3; i++) {
    console.log("Iteración: " + i);
}

7. Funciones Avanzadas y Closures

Bloques de código reutilizables. Las funciones pueden retornar valores y contener lógica interna encapsulada.

const multiplicar = (a, b) => a * b;
console.log(multiplicar(4, 5)); // 20
